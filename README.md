## 👋 About Me

Hi, I'm **Joel Joseph**, a software engineer at **Tata Consultancy Services (TCS)** from Kerala, India. I build Java and Spring Boot backends and the GenAI features that run on them, and I like turning ideas into working products.

- ☕ **Backend:** Java, Spring Boot, REST APIs and microservices with Kafka, secured with Spring Security, JWT and OAuth 2.0
- 🤖 **GenAI and agents:** LLM applications, RAG, and multi-step agents with LangChain, LangGraph and MCP
- 🌐 **Full stack:** React, Angular, TypeScript, Node.js, FastAPI and Django
- 📱 **Mobile:** a Flutter and Firebase grocery app, live on the Play Store
- ☁️ **Delivery:** Docker, Kubernetes, Jenkins CI/CD, AWS and Azure
- 🎓 **Learning:** MCA at Sikkim Manipal University, with a BCA from Kristu Jyoti College
